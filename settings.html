The connection profile Cairn uses to write memory. This must not be your roleplay model — roleplay models write flowery summaries. Cairn summarises each message after a reply arrives, starting after the newest summary Qvink Memory wrote, and waits while Qvink is enabled with Auto Summarize on. Appends each generation to data/<user>/user/files/cairn-inspector.jsonl, so a run can be read without copying numbers out by hand.
Keeps a lorebook entry in the prompt once it has activated, instead of letting it drop out on a turn whose keyword scan happens to miss it. Costs a few hundred tokens of stale lore; saves a full prompt rebuild each time an entry flickers.
The most of the prompt your lorebook may take. SillyTavern's own cap ships at 0 — no cap — so only its 25% budget binds, and on a large book that is more than the character card costs. Lowering this hands the difference to memory. 0 leaves SillyTavern's budget alone. This is SillyTavern's own setting, so it applies to every chat, not just this one.
Lets Cairn put the summaries into the prompt and keep the messages they cover out of it, instead of Qvink Memory doing both. Cairn waits until Qvink is silent — disable it, or set its short- and long-term memory position to Macro Only and turn off Exclude messages after threshold — and says below what it is waiting for.
Keeps track of the current scene — where it is, the weather, who is there, and each character's hair and outfit — and puts it in the prompt just above your newest message. It is brought up to date after each reply, and waits while WTracker or WTrackerLite is loaded.
Reads the whole story's index and asks the memory model to choose the few facts the rest of it cannot be understood without — a death, a promise, a debt, where someone came from — and keeps those one-liners at the top of the memory block. It is chosen again as the story grows, so a fact it gets wrong is not permanent.
How many of those lines to keep. The model is asked for exactly this many, which is what stops it calling everything important. The spine of a story does not grow as the story does, so a long chat wants about the same number as a short one.
